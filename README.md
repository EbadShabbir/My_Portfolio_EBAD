# Ebad Shabbir Portfolio

Interactive neon/cyber portfolio built with React, Vite, Framer Motion, and custom canvas particles.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deploy on Vercel

1. Push this project to GitHub.
2. Import the repository in Vercel.
3. Keep the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.
